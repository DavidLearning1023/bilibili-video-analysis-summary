# 视频类型 → 细节呈现指引

> **这份文件解决一个问题**：同一个框架，不同类型的视频，哪些细节该加厚、哪些该压掉、该换什么形式呈现。
>
> **红线：只调「细节呈现」，不动「分析逻辑与框架」。** 四大核心部分（视频概览与定性 / 视频核心总结 / 评论区概览与总结 / 评论区核心总结）+ 两个后置（关键参数与时间点 / 内容纠偏）+ 延伸发散，这个骨架**任何类型都不许改**。改的是每一块里装什么、用什么形式装。
>
> **为什么要写成文件而不是每次靠模型判断**：靠模型判断会漂移——同一类型的两期视频可能长出两套结构，用户翻笔记时认知负担变高。写死了才能稳定复现。

---

## 一、先判类型（三步，30 秒内完成）

```
第 1 步：看「有没有可核对的硬数据」
        有版本号 / 参数 / 性能数字 / 报价 / 政策条文 → 偏 A / C / E
        没有，主要靠讲道理或讲情绪           → 偏 D / G / H

第 2 步：看「说话人是一个还是一群」
        单人主讲          → A / C / E / F / G / H
        多人对话 / 访谈 / 圆桌 → B（说话人归属是最大风险）

第 3 步：看「评论区是不是主战场」
        赞／币比 ≥20:1，或 评论数/点赞数 >10%  → 评论区权重拉满（H 型的信号）
        赞／币比 1–3:1，评论少而精            → 视频权重正常
        评论区关闭 / 无评论                   → 走 F 型的「替代性校验」
```

**判定口诀**：先看有没有硬数据，再看有没有多个说话人，最后看评论区是不是主战场。

---

## 二、八个类型

| 代号 | 类型 | 一句话识别 |
|---|---|---|
| **A** | 技术 · 工具 · 部署 | 有参数要照抄、有性能要复核、有坑要避 |
| **B** | 深度访谈 · 对谈 | 多人说话，观点容易安错人头 |
| **C** | 财经 · 市场 · 投资 | 有行情/报价/预测，口径五花八门 |
| **D** | 商业 · 公司分析 | 拆解某个产品或公司的成败 |
| **E** | 政经 · 政策 · 宏观 | 政策、产业、地缘，事实与判断混杂 |
| **F** | 科普 · 健康 · 教育 | 给操作建议，与身体/生活直接相关 |
| **G** | 方法论 · 教程 | 教你怎么做事，价值在可迁移 |
| **H** | 娱乐 · 亚文化 · 段子 | 情绪型内容，视频没信息量 |

> 混合类型（例如「财经 + 访谈」）取**主类型**跑框架，再叠加次类型的一到两个特有节。

## 三、逐型指引

### A · 技术 / 工具 / 部署

**识别特征**：出现版本号（`v0.16.0-rc2`）、命令行参数（`-c`、`kv_mem_budget`）、性能单位（tok/s、tok/s·卡）、GitHub 仓库地址。

| 项 | 做法 |
|---|---|
| **定性卡** | 再加两个字段：**「能解决什么问题」**（一句话）+ **「成熟度」**（原型 / 可用 / 生产就绪） |
| **第 1 章** | 1.1 数据来源与可靠性边界**提到最前**（这类视频 AI 字幕误转最严重，必须先声明）；1.2 它要解决的痛点（配**显存/成本账本表**）；1.3 技术定位（归到哪条路线） |
| **第 2 章「本论」** | 不从"论证链"走，改走**机制拆解 + 工作流程**（分步骤），最后单列「这个设计选择的统一点在哪」 |
| **第 3 章** | 图表用**参数对比条**（不同硬件/量化档位的实测对比） |
| **第 4 章** | 对照维度是**「视频说的配置」vs「评论区实测的配置」**，重点找"没按作者推荐做、反而更好"的反例 |
| **第 5 章「关键参数」** | 列定义：**参数名 / 建议值 / 取值范围 / 调错会怎样**。四个列缺一不可 |
| **后置** | 「内容纠偏」里**误转清单必须保留全量**（技术类术语错一个就全错），不适用"只留影响理解的"规则 |
| **标题措辞** | 用「XX 部署方案」「XX 全纪实」「XX 怎么选」 |

**这一类最常见的杀手锏**：找到**评论区里第三方实测的硬件 + 数值**，和作者自测对不上就对上了——对上了是"数据可信"，对不上就"两边都列"。

---

### B · 深度访谈 / 对谈

**识别特征**：一问一答、圆桌、多人连线。字幕**没有说话人分离**是本型最大风险。

| 项 | 做法 |
|---|---|
| **定性卡** | 加**「受访者」**与**「采访者」**两个字段；再加「这期的信息密度」 |
| **第 1 章** | 1.1 说话人表（谁是谁、什么身份、什么立场）；1.2 本期真正有信息量的观点清单 |
| **第 2 章「本论」** | **按话题分段**，不按时间。每段标注「谁说的」 |
| **第 3 章** | 图表用**立场谱**（同一话题上，各方的位置） |
| **第 4 章** | 对照维度是**「受访者的观点」vs「评论区的补充/反驳」** |
| **第 5 章** | 常常为空 → 整节省略（不要硬凑） |
| **后置** | 必须有**「说话人归属不明」单列一节**——用年龄、生平、上下文称谓三方交叉反推 |
| **反陷阱** | 术语"不规范"不等于转写错误：受访者本人可能就这么说。先搜「受访者 + 该术语」再下结论 |
| **标题措辞** | 用「XX 访谈：他真正说了什么」 |

---

### C · 财经 / 市场 / 投资

**识别特征**：出现点位、涨跌幅、PE、目标价、政策日期、标的名称。

| 项 | 做法 |
|---|---|
| **定性卡** | 加**「时间敏感性」**字段（这类内容过期最快）+「谁的利益」 |
| **第 1 章** | 1.1 **数字账本**（所有数字 + 口径 + 出处）；1.2 时间线（什么时点发生了什么） |
| **第 2 章「本论」** | 用**「多方观点拆解」**代替单一论证链：谁、什么立场、论据是什么、**他是利益相关方吗** |
| **第 3 章** | 图表用**价格带 / 区间对比** |
| **第 4 章** | 对照维度是**「预测 vs 已发生的事实」**；评论区里的**水军/引流痕迹单列一节**（这类视频高发） |
| **第 5 章** | 列定义：**指标 / 视频说法 / 权威口径 / 差异** |
| **后置** | 「延伸发散」里必须有**「如果只想要一个结论」**这一段（读者多半只想抄作业） |
| **红线** | **绝不能把视频里的预测写成事实**——本型最高频的翻车点。所有前瞻性表述一律加"预测/推演"前缀 |
| **标题措辞** | 用「XX：时间线推演」「XX 三方观点拆解」 |

---

### D · 商业 / 公司分析

**识别特征**：分析某产品为什么成/败、某人的商业决策、某场商战。

| 项 | 做法 |
|---|---|
| **定性卡** | 加**「分析对象」**与**「作者的立场是否中立」** |
| **第 1 章** | 1.1 分析对象的事实基线（这家公司/这个人到底做了什么）；1.2 作者的因果主张 |
| **第 2 章「本论」** | **因果链拆解**：把"因为 A 所以 B"逐环拆开，标注哪一环是硬事实、哪一环是作者的推断 |
| **第 3 章** | 图表用**竞争坐标**（横向比同类） |
| **第 4 章** | 对照维度是**「作者的因果解释」vs「从业者/内部人给的另一套解释」** |
| **第 5 章** | 列定义：**关键经营数字 / 来源 / 是否可核实** |
| **体例** | 允许在正文前加**「先说三个判断」**（把结论压到最前面，形态灵活） |
| **标题措辞** | 用「XX 为什么成功/失败」 |

---

### E · 政经 / 政策 / 宏观

**识别特征**：政策文件、产业规划、地缘博弈、国家级数据。

| 项 | 做法 |
|---|---|
| **定性卡** | 加**「事实可靠度」**（哪些是公开文件、哪些是转述） |
| **第 1 章** | 1.1 政策/事件的**时间线**；1.2 视频的核心论断 |
| **第 2 章「本论」** | **逐论断核验**：每条论断 → 支撑材料 → 是否成立 |
| **第 3 章** | 图表用**时间线 / 对比条**（不要用饼图这类弱表达） |
| **第 4 章** | 对照维度是**「与官方口径的差异」** |
| **第 5 章** | 列定义：**数据项 / 数值 / 发布机构 / 发布时点** |
| **后置** | 「延伸发散」**加重**（这类内容的价值一半在发散）；本轮实测有做到 7 条发散 |
| **红线** | 涉及国家主权、领土、政治敏感议题时，一律以官方表述为准，不引用讽刺、不展开争议 |
| **标题措辞** | 用「XX：统筹规划 vs 自由市场」这类对照式 |

---

### F · 科普 / 健康 / 教育

**识别特征**：给身体或生活的操作建议；有"多久""多少次""多少剂量"这类量。

| 项 | 做法 |
|---|---|
| **定性卡** | 加**「适用人群」**与**「风险等级」** |
| **第 1 章** | 1.1 核心框架（把专业知识压成一句能记住的话）；1.2 **操作建议清单**（这是读者真正要的） |
| **第 2 章「本论」** | **按问题分块**：每个问题给"结论 → 依据 → 边界条件" |
| **第 3 章** | 图表用**阈值/剂量刻度**（"多少算过度"这类判定标准要画出来） |
| **第 4 章** | 对照维度是**「视频的说法」vs「权威指南/文献」** |
| **第 5 章** | 列定义：**项目 / 视频给的数 / 指南给的数 / 谁更保守**。单列一节**「三个最值钱的具体数字」** |
| **评论区关闭时** | 第 3 章整章改为**「替代性校验」**：用外部文献/指南代替评论区，并**把"评论区关闭"本身当作一条判断写出来** |
| **红线** | 健康类内容**必须给"什么时候该去看医生"的边界**，不能只转述 |
| **标题措辞** | 用「XX：该有的都有了」这类保留原意的写法 |

---

### G · 方法论 / 教程

**识别特征**：教你做事的步骤、提示词、工作流、学习路径。

| 项 | 做法 |
|---|---|
| **定性卡** | 加**「前置要求」**（学这个要先会什么）与**「可迁移性」** |
| **第 1 章** | 1.1 它要解决的具体痛点；1.2 方法的核心机制 |
| **第 2 章「本论」** | **操作流程 + 决策点**：每一步"如果 X 则 Y" |
| **第 3 章** | 这一型**常把第 3 章替换为「同赛道横向对比」**——把视频提到的方法和市面上的同类方案横向拉平比较，比看评论区更有价值 |
| **第 4 章** | 对照维度是**「视频的方法」vs「同类方法」vs「评论区补充的替代方案」** |
| **第 5 章** | 列定义：**步骤 / 具体做法 / 常见错误** |
| **后置** | 允许设**「可复用的方法论清单」**整章（坑、配方、决策树） |
| **标题措辞** | 用「XX：写代码之前先让 AI 拷打你」这类保留原题钩子的写法 |

---

### H · 娱乐 / 亚文化 / 段子

**识别特征**：赞／币比 ≥20:1、评论数/点赞数 >10%、时长很短、无岗位/参数/政策信息。

| 项 | 做法 |
|---|---|
| **定性卡** | 核心填**「数据侧写」**（币/赞比、评论占赞比），用它直接给视频定性；填「价值在哪」时**明确把重心指向评论区** |
| **第 1 章** | 1.1 用比值定性；1.2 核心主张与**它的隐含前提**；1.3 逐项判定表；1.4 分人群价值 |
| **第 2 章「本论」** | **极简**：只保留"逐拍时间线 + 链条断在哪几处"。段子没有论证，别硬拆 |
| **第 3 章** | 图表用**币赞比对比条 + 观点聚类小倍数图**（这一型评论区是主战场，聚类必须做） |
| **第 4 章** | 对照维度是**「视频的说法」vs「评论区的修正」vs「影响」**三栏 |
| **第 5 章** | 这一型叫**「关键参数与对照时间点」**："参数"其实是梗与台词 |
| **后置** | 「延伸发散」允许**方法论层面的发散**（例如"为什么这类视频一定会火"） |
| **标题措辞** | **照录原视频标题**，不加评论 |
| **红线** | 别把段子当信息源批判——判定的对象是它的**数据形态**，不是它的内容对错 |

## 三·五、评论区四形态（与八型正交，2026-10-19 新增）

**为什么必须有这一维**：八型回答的是"这类视频的报告长什么样"，但**决定评论区怎么读的不是视频类型，是评论区自己的形态**。同为 E 型政经：

- 《社保便宜了谁》：4,099 条，8 簇，「视同缴费」认同 27.4% / 争议 31.0% → 这是**辩论**
- 《菲佣与汇款》：594 条，6 簇，认同第一是"我家姐姐很好"27.4%，**无一条核对数字** → 这是**经验交换**

同一张类型卡套下去，前者要逐簇做绪论/本论/结论，后者做三簇就空了。

### 判别（三个便宜指标，取数即得，不用读图）

| 形态 | 判别信号 | 读法 |
|---|---|---|
| **辩论场** | 评论/赞 >15%、楼中楼/顶层 >1.2、图片占赞 <10% | 三轴聚类 + 逐簇对照；主战场那簇展开最厚 |
| **举证场** | 图片占样本赞量 >15%，且图片尺寸大（>800px 宽） | **先读图再读字**，图是论据本体 |
| **表演场** | 含图条数 >30%，或 评论/弹幕 >2，赞币比 >20:1 | 按行为分层（@ / 表情 / 观点），比例本身就是结论 |
| **空场** | 评论多但集中在元话题（商单、UP 主、玩梗），核心论点提及率 <5% | 报告要写明"视频的论证没有进入讨论"，这是发现不是缺陷 |

> 四个形态的实测样本（2026-10-18 跑批）：
> 表演场＝缇宝（含图 57%、图片占赞 96.8%）；举证场＝刹车（图片占赞 35.0%）、棍木（25.4%）、巫师（条数仅 5% 但占赞 28.3%）；
> 辩论场＝社保（评论/赞 21.9%、楼中楼 27.6%）；空场＝巫师（981 条评论里"世界模型/数字孪生/仿真"出现 0 次）。

**"图片占赞"要用顶层评论算**。楼中楼每楼只取 3 条（截断），混进来会把比例稀释。脚本已按顶层统计。

**混合形态**：一个视频可以前半段辩论、后半段表演（例如高赞区是梗图、中赞区是长论证）。此时按**赞量分布**分段读，不要只贴一个标签。

## 四、所有类型共用的部分（不许改）

| 部分 | 为什么不能改 |
|---|---|
| 四大核心部分的顺序 | 「先定性再展开、先视频再评论区」是这套方法论的骨架 |
| 时间戳必须是可点链接 | 用户要能一秒回原片核对 |
| 三源区分（视频说 / 评论说 / 我推断） | 混淆三者等于把推断伪装成事实 |
| 内容纠偏与关键参数**后置** | 它们是速查层，不是阅读主线 |
| 「评论是用户原生文字、可靠性高于字幕」这句声明 | 它是整条方法论的前提 |
| 「AI 字幕不可直接引用」 | 唯一一处宁严勿松的规则 |
| 报告不含读者个人信息 | 报告要能对外分享 |

## 五、怎么用这份指引

```
1. 三部判定法先定类型（30 秒）
2. 打开对应类型卡，照表调整：
   定性卡字段 → 第 1 章小节 → 第 2 章呈现形式 → 第 3 章图表 → 第 4 章对照维度 → 第 5 章列定义 → 后置取舍
3. 混合类型：主类型跑框架 + 次类型叠加 1–2 个特有节
4. 拿不准归哪型：按 H 型最小骨架写，宁可少不要错
```

**改这文件的前提**：只有在**积累了新的同类型实例、并且发现现有指引某一格给错了**时才改，改完在 `CHANGELOG.md` 记一笔。不要因为"某期视频不太一样"就加一格——例外多了，这份文件就失效了。
